# AYÉ — prévisualisation publique actualisée

Ce dossier prépare une **démo statique distincte** du site GitHub Pages existant. `index.html` est autonome : JavaScript et CSS sont intégrés dans le fichier pour pouvoir l’envoyer facilement depuis le navigateur GitHub.

## Avant publication

- Le site actuel `https://rorolulu2019-eng.github.io/AYE/` n’est pas modifié.
- Aucun dépôt n’a été créé ni publié par cette préparation. Le nouveau lien n’existera qu’après les étapes ci-dessous.
- La démo s’exécute dans le navigateur, en mémoire de l’onglet. Elle ne crée pas de compte et n’envoie pas les réponses, dates de naissance ou notes à une API.
- Aucun paiement SasPay ni message WhatsApp n’est envoyé. Les clés et le PDF culturel source ne sont pas inclus.
- Le mapping Vodún/Ange-Archange reste affiché comme un rapprochement symbolique, distinct d’une attribution traditionnelle personnelle et d’une consultation du Fa.

## Publication via l’interface web, sans toucher à l’ancienne page

1. Télécharge et décompresse `AYE_GitHubPages_Actualisee.zip`. Il contient `index.html` et ce guide.
2. Connecte-toi toi-même à GitHub dans ton navigateur, puis crée un **nouveau dépôt public** nommé `aye-v1-preview` (ne choisis pas le dépôt existant `AYE`). Tu peux cocher l’option qui ajoute un README.
3. Dans le nouveau dépôt, choisis **Add file → Upload files**. Envoie uniquement le fichier `index.html` extrait de l’archive, puis valide **Commit changes** sur la branche `main`.
4. Ouvre **Settings → Pages**. Sous **Build and deployment**, choisis **Deploy from a branch**, sélectionne `main` et `/(root)`, puis clique **Save**.
5. Attends que la publication soit terminée (souvent quelques minutes). Vérifie le statut dans **Settings → Pages** ou dans l’onglet **Actions**.

Si le dépôt est créé dans le compte `rorolulu2019-eng`, le lien de prévisualisation attendu est :

`https://rorolulu2019-eng.github.io/aye-v1-preview/`

Si tu utilises un autre compte GitHub, remplace `rorolulu2019-eng` par ton nom d’utilisateur. **Ce lien attendu ne devient actif qu’après la publication.** L’ancienne démo reste disponible à son adresse durant toute la validation. Ne remplace pas encore les fichiers du dépôt `AYE` ; on pourra le faire séparément après vérification et ton accord.

Aucun mot de passe, jeton ou secret GitHub ne doit être envoyé dans le chat. La connexion se fait uniquement dans ton navigateur GitHub.
